# Portfolio de Josias Kouraogo

Site statique HTML/CSS/JavaScript pour GitHub Pages.

## Fichiers
- `index.html` : accueil
- `projets.html` : projets académiques et techniques
- `experiences.html` : expériences
- `formation.html` : parcours académique
- `competences.html` : compétences
- `contact.html` : contact
- `style.css` : design responsive
- `script.js` : menu mobile et année automatique

## Avant publication
1. Remplacer `VOTRE-EMAIL@exemple.com` dans `contact.html`.
2. Ajouter le vrai lien LinkedIn.
3. Ajouter le CV PDF dans `assets/CV_Josias_Kouraogo.pdf`.
4. Ajouter une photo portrait et des images de projets si vous souhaitez en afficher.
5. Relire les projets et retirer toute compétence ou tâche qui ne correspond pas exactement à votre expérience.
6. Vérifier les dates et intitulés de formation.

## Publier avec GitHub Pages
1. Créez un dépôt public nommé `VOTRE-PSEUDO.github.io` sur GitHub.
2. Téléversez tous les fichiers de ce dossier à la racine du dépôt.
3. Ouvrez `Settings` → `Pages`.
4. Dans `Build and deployment`, choisissez `Deploy from a branch`, branche `main`, dossier `/(root)`, puis `Save`.
5. Attendez la publication, puis ouvrez `https://VOTRE-PSEUDO.github.io`.

GitHub Pages publie les fichiers statiques. Le site est public : ne publiez pas de coordonnées privées ou de documents confidentiels.
